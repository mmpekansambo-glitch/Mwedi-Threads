# New page layouts (web): prompts and decisions

Issue #119, built on the new look (#118). Built with Claude Code in a cloud session from my Mwedi Threads project (thread "Redesign the app's look and personality").

## Prompts I gave

1. "I envision a dashboard for the projects, tools and more that is stagard like this image" (a masonry board)
2. "I like the idea of this layout for when someone clicks on one of the project tiles ... it feels like a social networking app to an extent"
3. "For the notes notice board I like this" (a row of cards)
4. "Not really. I feel like it is too boxy still" / "What would it look like without the icons?"
5. Picked "Mix B with A": open pages with no containers, and pinned swatches only for notes and key cards.
6. "go ahead"

## Decisions

- **Overview:** "Evening, Ngwe." with the counts as words you can click. "This week" is a strand of yarn that fills in on crafting days. A pinned "Pick up where you left off" swatch, pinned note swatches with their own tints, then "On the hook" (Yarn studio) or "On the table" (Sewing room) as floating tiles. The yarn brand and finishing stats, the charts, the stage counts and the fabric chart stay lower down.
- **Projects boards:** word filters (All, each status, Starred) with a running-stitch underline, then floating, slightly tilted tiles: the photo or the name in its craft font, with the status underneath.
- **Project pages:** text actions under the title, the project pinned on the right, facts without a box, and a floating bar. Yarn: "Row 24 · +1 row · Add a note". Sewing: "Cut done" moves the project on to its next stage (or "Mark finished" at the last stage), plus "Add a note".
