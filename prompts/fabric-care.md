# Sewing room: fabric care instructions: prompts and decisions

Issue #100. Built with Claude Code in a cloud session from my Mwedi Threads project (thread "Add fabric care instructions").

## Prompts I gave

1. "Build in fabric care instructions as an optional piece « + Add Care Instructions » button that uses laundry symbols to denote specifics"
2. Picked "Build as shown" after seeing a mockup of the button, the five rows, the symbol grid and the full symbol set.

## Decisions

- **Closed by default:** the fabric form shows one "+ Add care instructions" button, so the form stays light for makers who don't need it.
- **Five optional rows:** Wash, Bleach, Dry, Iron and Dry clean. Remove clears them all and folds the section away.
- **Symbol grid, not a wheel:** each row opens a grid of the symbols with their names, because symbols are easier to tell apart side by side. One pick per row; Clear empties a row.
- **21 symbols, drawn for the app** (no third-party images): Machine 30°/40°/60°, Gentle 30°, Hand wash, Do not wash; Any bleach, Non-chlorine only, Do not bleach; Tumble low/normal, Do not tumble, Line dry, Dry flat, Drip dry; Iron low/medium/high, Do not iron; Dry clean, Do not dry clean. The web and phone app draw them from the same shape data.
- **Where they show:** on the fabric's own page (which is its edit form), not on the stash cards.
- Works on web and mobile.
