# Sewing room pattern stash: prompts and decisions

Issue #105. Built with Claude Code in a cloud session from my Mwedi Threads project (thread "Add pattern stash to Sewing room").

## Prompts I gave

1. Original ask: "Under the stash in the sewing room, can we make an allowance for fabric and separately pattern stashes?"
2. "re-ask the above with clickable options"
3. Answered five tap cards.

## Decisions

- **Where it lives:** its own Patterns link in the web sidebar and its own Patterns tab on the phone, next to Fabric. The phone's Sewing room now has five tabs.
- **Fields (light set):** Name (required), Designer, Type on a wheel, Format on a wheel (Paper, PDF, Magazine, Self-drafted), Sizes and Notes.
- **Photo:** an optional cover photo, because PDF and self-drafted patterns often have no envelope.
- **Projects:** the typed Pattern and Designer boxes on a sewing project became one Pattern row that picks from the pattern stash, or adds a pattern that isn't saved yet. Patterns typed on older projects move into the stash on their own.
- **Times made:** each pattern shows how many finished projects used it. No archive for patterns.
