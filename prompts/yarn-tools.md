# Yarn studio Tools: prompts and decisions

Issue #75. Built with Claude Code in a cloud session from my Mwedi Threads project (thread "Add tools to the Yarn studio").

## Prompts I gave

1. Original ask: "Can we add a tools featrue to the Yarn studio"
2. "Catalogue the types of hooks and etc that a user has"
3. "all recs"

## Decisions

- **What it is:** a catalogue of the hooks, needles and other tools I own. It is separate from the counter card on each project page.
- **Sections:** Hooks, Needles and Notions, like the Sewing room's Notions and Kit.
- **Hooks:** size from the same list projects use, material (aluminium, steel, bamboo, wood, plastic, ergonomic) and how many. Brand, name, notes and photo are optional.
- **Needles:** size, type (straight, circular, double-pointed, interchangeable), cable length for circular and interchangeable needles, material and how many.
- **Notions:** stitch markers, tapestry needles, row counter, cable needles, scissors, measuring tape, blocking mats, blocking pins, yarn swift, ball winder, and Other.
- **Linking to projects:** not yet.
- **Hints about sizes I don't own:** none.
- Works on web (a new Tools link in the Yarn studio sidebar) and on mobile (a fourth Yarn studio tab).
