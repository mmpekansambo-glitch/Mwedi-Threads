# Designer field on one row: prompts and decisions

Issue #23, branch `feature/designer-one-row`, PR #24. Built with Claude Code in a cloud session (thread "Design refresh and font sizes").

## Prompts I gave

1. "Where do I input if I choose name for design?"
2. "Hmmmm that makes it look like they are two separate portions and not connected inputs. Can we make them one in a way? A toggle on the left snd input to the right of Design name? Then get rid of design."

## Decisions

- One "Designer" field: the Name / Website switch on the left and the box on the right, on the same row.
- The separate "Design" heading is gone.
- In website mode, the "Preview page title" button sits on the same row.
- Web and mobile.
