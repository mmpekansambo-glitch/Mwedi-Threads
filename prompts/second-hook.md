# Second hook size: prompts and decisions

Issue #59. Built with Claude Code in a cloud session from my Mwedi Threads project (thread "Add second crochet hook size").

## Prompts I gave

1. Original ask: "Can we include the ability to include a secondary hook size under the crochet projects? So some projects may use two different hook sizes, thus I want that to be able to show up as an option."
2. "Second hook; stop at two. Project page strictly"

## Decisions

- **Label:** plain "Second hook", with no note about what it's for.
- **How many:** two hooks at most. An "Add a second hook" button opens the second picker, and Remove takes it away again.
- **Sizes:** the same list as the main hook.
- **Where it shows:** only on the project page, under the main hook. Not on project cards.
- Works on web and mobile, in both the new-project and edit forms, like the second knitting needle.
