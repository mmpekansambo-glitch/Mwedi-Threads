# Sewing room: unchecking a stage tapped by mistake: prompts and decisions

Issue #94. Built with Claude Code in a cloud session from my Mwedi Threads project (thread "Add machine settings to sewing projects").

## Prompts I gave

1. "Can we give people the opportunity to uncheck a progress step incase they unintentionally checked it"
2. Picked "Sewing stages" when asked whether this meant the sewing stages, the yarn pattern sections, or both.

## Decisions

- Tapping the current stage again unchecks it and steps the project back one stage (Sew goes back to Cut).
- Unchecking Prep puts the project back to Not started (Planning).
- Other stages still work as before, and a finished project still uses Reopen project.
- Web and phone. No database change.
