# Knitting needles: prompts and decisions

Issue #25, branch `feature/knitting-needles`, PR #26. Built with Claude Code in a cloud session (thread "Knitting tools").

## Prompts I gave

1. Original ask: "Let's update the tools for knitting now"
2. "I want these options similr to how the crochet project works" (with a needle size chart attached)
3. Picked on the decision cards: size list, type plus cable length, main plus second needle.

## Decisions

- Before, knitting projects only had a free-text Tools box.
- **Size:** picked from a list, 2.0 to 25 mm, shown with US and UK/Canada sizes, like crochet hooks.
- **Type:** straight, circular, double-pointed or interchangeable. Cable length only appears for circular and interchangeable.
- **How many:** a main needle plus an optional second one (for example for ribbing).
- Old Tools notes are kept and shown as "Saved tools note".
- Web and mobile, in New project and Edit details.
