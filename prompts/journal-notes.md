# Edit and delete journal notes: prompts and decisions

Issue #58. Built with Claude Code in a cloud session from my Mwedi Threads project (thread "Edit and delete journal notes").

## Prompts I gave

1. Original ask: "Create a request such that one can edit the progress notes they make in the journal, full stop, as well as being able to delete the notes if they so wish. Use a swipe right to delete, swipe left to edit methodology."
2. "Swiping on the phone but some button connectivity on the web page"
3. "Create a bubble to the right-hand side of the web options, which people can click to edit or delete. Full stop. Let the bubble include the three dots or ellipses inside them and be highlighted. Please draft an image for me to review before pushing this request."
4. "Actually match the iphone preferences"
5. "Build now"

## Decisions

- **Phone:** swipe left on a note to delete it and swipe right to edit it, the same as iPhone apps like Mail and Messages. (My first ask had these the other way round.)
- **Web:** a highlighted Powder Blue ⋯ bubble at the top right of each note. Clicking it turns it Granite and opens Edit note and Delete note.
- **Deleting:** always asks "Delete this note?" first.
- **Editing:** everything can be changed: the text, the progress number, the date and the photo.
- **"Edited" label:** none.
- **Project progress:** always follows the newest note that's left. Deleting or lowering the note that hit 100% moves the project back to In progress.
