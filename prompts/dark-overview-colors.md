# Dark mode Overview colors: prompts and decisions

Built with Claude Code in a cloud session from my Mwedi Threads project (thread "Make dark mode less monotonous").

## Prompts I gave

1. With a screenshot of the dark Yarn studio Overview: "This page looks fulsome but too monotonous in a way. How can we work on improving the appearance of the app especially in dark mode?"
2. "The outlook in Light mode is so much more pretty."
3. Picked "A + C mix" from four options: A palette tints, B moonlight gold, C fewer boxes, or A + C.

## Decisions

- **Stat cards get their own palette tint** in dark mode, like light mode's tints: All projects deep Powder Blue, In progress deep Lavender, Finished deep Granite. The number and doodle on each card use the matching light shade.
- **The second row** (most-used yarn brand, average days) stays plain slate, so the three tinted cards stand out.
- **Charts:** one color per status (Planning Lavender, In progress Powder Blue, On pause Blue Slate, Finished Granite green). Finished per month is green and notes per week is Lavender.
- **"This week" is the one bright block:** Lavender with dark text in the Yarn studio and light mauve in the Sewing room.
- **Sewing room:** mauve takes Granite's place, so the Finished card is deep mauve and nothing turns green.
- **Light mode is unchanged.**
- Web and phone. No database change.
