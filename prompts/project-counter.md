# Project counter: prompts and decisions

Issue #56. Built with Claude Code in a cloud session from my Mwedi Threads project (thread "Tools tab and row counter").

## Prompts I gave

1. Original ask: "I also want to include a 'tools' tab that can sub select between knitting sewing and crochet. In crochet I want to build in a row counter or stitch counting tool."
2. "Draft an image for the counter style", then "What of the counter style on the website?"
3. "A counter is only relevant to knitting & crochet and not sewing."
4. "I like the separate tool instead. But I don't want to distinguish between rows or stitches. I just want it to be a basic counter."
5. "Draft images please", "make web mockups as well".
6. "I like the saved with project one but remove the 'sewing' from the banner."
7. "Inside the project please."

## Decisions

- **Style:** one plain counter with a big number, + and −, Undo and Reset. No rows or stitches labels.
- **Where:** a card on every crochet and knitting project page, on web and mobile. No Tools tab, and nothing for sewing.
- **Saving:** the count is saved with the project, so phone and web show the same number. It never changes the project's progress, and counting doesn't move the project up the "recently updated" order.
- **Website:** the space bar adds one (not while typing in a box). **Phone:** a small buzz on each tap.
- Quick taps are saved together after a short pause instead of one request per tap.
