# Weekly crafting goal: prompts and decisions

Issue #104. Built with Claude Code in a cloud session from my Mwedi Threads project (thread "Add weekly crafting habit goal").

## Prompts I gave

1. Original ask: "Bake in a habit tracker for sewing and yarn studio that allows you to input a weekly goal tracked by the number of note updates in the projects."
2. After the first mockup (goal counted in notes): "I want the notes to be a factor of tracking, but not how the goal is set per se."
3. Picked "Crafting days per week" from three options (days, hours, projects moved forward).
4. "your recs" for the remaining choices.

## Decisions

- **Unit:** the goal is crafting **days** per week. Notes are one way a day fills in, not the goal itself.
- **What fills a day:** a journal note, a tap on a yarn project's row counter, or the **I crafted today** / **I sewed today** button on the card.
- **One goal per studio.** Yarn studio activity only counts toward the yarn goal, and Sewing room activity only toward the sewing goal.
- **Weeks start on Monday**, on the maker's own calendar (their time zone).
- **One "N weeks in a row" line**, shown from 2 weeks. There are no badges or other extras.
- **Goal wheel** from 1 to 7 days, plus **Turn off goal**.
- **Deleting a note keeps the day**, because the maker still crafted that day. Moving a note to another date counts the new day as well.
- **Where:** a "This week" card at the top of each studio's Overview, on web and phone.
